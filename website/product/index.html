Product

Four modes, one idea.

Amon is being shaped around a simple progression: find public information, read it more clearly, enter the real website only when the task needs it, and keep intentional work in a local workspace.

01 · Search / Browse

Fast entry into the public web.

Search / Browse is the lightweight starting point. The current backend direction is to support search and retrieval transiently so the service helps with access without becoming a durable archive of each search step.

  1. Start with a query and get relevant public results.
  2. Inspect sources without committing every step to long-term storage.
  3. Move deeper only if the material is worth attention.
02 · Clean View

Focused reading, not page clutter.

Clean View is for the moment when a source matters and you need to actually read it. The aim is a quieter surface that keeps the content and removes much of the surrounding noise.

  1. Preserve the substance of the source.
  2. Reduce ads, interface debris, and unnecessary chrome.
  3. Make it easier to save the useful parts into your local workspace.
03 · Protected Session

For selected tasks that need the original website.

Some work cannot stay inside clean reading. Protected Session is the mode for public-web tasks that require the live website itself, such as interactive flows, forms, or pages that cannot be reduced safely.

  1. Use it when the task needs the real site.
  2. Keep it scoped instead of making every browsing step equally exposed.
  3. Be explicit that the website you visit still has its own visibility and rules.
04 · Workspace

Local by default for the things you decide to keep.

Workspace is where deliberate saving belongs. The current product direction is local storage for saved sources, excerpts, and working material so “what I kept” is treated differently from the transient work of search and retrieval.

  1. Save sources, excerpts, and related working material intentionally.
  2. Keep that material local by default.
  3. Make the saved workspace the durable layer, not every browsing action.
How it fits together

Progressive depth instead of one browser mode for everything.

The product model is intentionally not “just browse normally and sort it out later.” Amon separates quick discovery, deeper reading, selected protected sessions, and deliberate local saving so the user can make a better tradeoff at each step.

Search for reach. Clean View for focus. Protected Session for selected live tasks. Workspace for what you choose to keep.
Amon. Built around clearer boundaries.
