FAQ

Short answers, no hand-waving.

The public site should remove confusion, not add it. These answers keep the language aligned with the current product direction and the repo’s actual architecture.

What is Amon?

Amon is a product direction for working with the public web more carefully: private-by-default search and retrieval, cleaner reading, protected sessions for selected tasks, and a local workspace for the material you intentionally keep.

Is Amon a browser?

Not in the “replace every browser behavior everywhere” sense. The current public description is narrower: Amon helps with searching, reading, selected live-site tasks, and local workspace organization around public-web material.

What does private by default mean here?

It means the product is being designed to minimize durable service-side storage for queries, results, and page content, while treating saved user work as something that belongs in a local workspace by default.

What is Protected Session?

Protected Session is the mode for selected public-web tasks that need the real site itself, such as interactive pages or forms. It exists because some work cannot stay inside search and clean reading alone.

Is everything already finished?

No. The site intentionally describes the current product direction and architecture without claiming that every mode is fully mature or broadly available yet.

How do I request access?

Use the contact page or email hello@getamon.com. That is the simplest production-safe CTA for the first public site.
